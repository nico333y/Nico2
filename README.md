# Nico2

این پروژه یک اپ Android Native با Kotlin، Jetpack Compose و Material 3 است. رابط شامل صفحهٔ چت، تنظیمات، حافظهٔ محلی و گفتگوی صوتی Gemini Live است. گفتگوها و موارد حافظه در فایل JSON نسخه‌دار داخل فضای خصوصی اپ روی همان دستگاه ذخیره می‌شوند. حالت ناشناس تغییرات جدید را فقط تا پایان اجرای برنامه در حافظه نگه می‌دارد.

## Gemini

در تنظیمات API می‌توان کلید شخصی Google AI Studio را وارد کرد. کلید با AES-GCM و کلید Android Keystore در فضای خصوصی اپ رمزگذاری می‌شود. از فهرست API فقط مدل‌های `gemini-3.8-flash`، `gemini-3.7-flash`، `gemini-2.6-flash`، `gemini-3.5-flash-lite`، `gemini-3.1-flash-lite` و `gemini-3.8-live` نمایش داده می‌شوند. در صورت دریافت خطای سهمیهٔ `429`، چت متنی مدل متنی سازگار دیگری را امتحان می‌کند. گفتگوی زنده از Gemini Live، میکروفون و خروجی صوتی دستگاه استفاده می‌کند؛ برای شروع، اجازهٔ میکروفون لازم است. پاسخ setup در Gemini Live می‌تواند در فریم باینری WebSocket بیاید؛ اپ آن را به‌صورت UTF-8 JSON پردازش می‌کند و دریافت setupComplete پیش‌شرط شروع میکروفون است. با رفتن اپ به پس‌زمینه، ضبط متوقف می‌شود.

گفتگوی زنده زیرنویس موقت و نهایی ورودی کاربر و خروجی دستیار را از transcription خود Gemini Live نشان می‌دهد؛ متن نهایی هر نوبت یک‌بار به گفتگوی انتخاب‌شده افزوده می‌شود. تنظیم transcription ورودی، `fa-IR` و `tr-TR` را به‌عنوان **راهنمای تشخیص** می‌فرستد، نه محدودیت قطعی زبان. به دستیار هم دستور داده می‌شود فقط فارسی یا ترکی استانبولی صحبت کند و اگر ورودی را زبان دیگری یا نامطمئن تشخیص داد، درخواست تکرار کند. این دستور صرفاً راهنمای رفتاری است: Live API همچنان می‌تواند صدای زبان‌های دیگر را پردازش کند و برنامه فیلتر فنی زبان ورودی ندارد. در اپ فعلاً مسیر اجرای ابزار/فرمان صوتی تعریف نشده است.

صفحهٔ صوتی را می‌توان به پنل کوچک روی چت تبدیل کرد؛ تا وقتی اپ در پیش‌زمینه است، همان session و اتصال باقی می‌مانند و پنل کنترل بازگشت، قطع/وصل میکروفون و پایان را دارد. ورودی تایپی هنگام Live عمداً غیرفعال است، چون مسیر چت متنی درخواست مستقلی می‌فرستد و جزئی از همان Live session نیست. اعلان خصوصی وضعیت جلسه نیز با مجوز اعلان Android 13+ نمایش داده می‌شود و دکمهٔ قطع/وصل میکروفون و پایان دارد؛ متن مکالمه در اعلان قرار نمی‌گیرد. این اعلان تضمین ضبط پس‌زمینه نیست: اپ با رفتن به پس‌زمینه میکروفون و session را متوقف می‌کند؛ foreground service پس‌زمینه پیاده‌سازی نشده است.

**هشدار امنیتی:** این نسخه برای استفادهٔ شخصی است، نه انتشار. طبق راهنمای Google، کلید API در اپ موبایل قابل استخراج است؛ برای انتشار عمومی باید درخواست‌ها از یک واسط امن سمت سرور انجام شوند. کلید را وارد سورس یا مخزن Git نکنید و با دیگران به‌اشتراک نگذارید. ارتباط چت و صدای زنده به Google ارسال می‌شود؛ متن رونوشت‌های گفتگوی زنده در حافظهٔ محلی اپ می‌ماند.

پیوست‌های عکس، PDF و فایل متنی با محدودیت اندازه در فضای خصوصی اپ نگه‌داری می‌شوند و همراه پیام متنی به مدل‌های سازگار فرستاده می‌شوند. در Gemini Live می‌توان دوربین CameraX را روشن کرد تا پیش‌نمایش و فریم‌های JPEG با نرخ محدود (حداکثر ۱ فریم در ثانیه) به جلسهٔ زنده فرستاده شوند؛ ویدئو و صدای زنده به Google ارسال می‌شوند و فریم‌های CameraX در حافظهٔ محلی ذخیره نمی‌شوند. گرفتن عکس برای پیوست چت با دوربین سیستم انجام می‌شود. تنظیمات شخصیت، صدا، زبان برنامه و کاهش انیمیشن روی همین دستگاه ذخیره می‌شوند. رابط انگلیسی و ترکی موجود است.

همگام‌سازی ابری، Room، Firebase و Backend در این نسخه وجود ندارند. پشتیبان‌گیری و انتقال دستگاه برای داده‌های اپ غیرفعال است. Flutter استفاده نمی‌شود. استفادهٔ واقعی از دوربین، میکروفون، Gemini Live و ارسال شبکه به دستگاه Android و کلید معتبر نیاز دارد و در این محیط Codespace آزمون end-to-end نشده است.

اگر گفتگوی زنده شکست بخورد، صفحهٔ صوتی یک کد تشخیصی پایدار، شناسهٔ نشست، آخرین مرحلهٔ موفق و جزئیات پالایش‌شده را نشان می‌دهد؛ پاسخ HTTP سرور نیز در صورت وجود می‌آید. Listener هر دو نوع فریم متنی و باینری WebSocket را پشتیبانی می‌کند. رویدادهای WebSocket در Logcat با تگ `Nico2Live` ثبت می‌شوند؛ API key، صدای خام و متن پیام‌های دریافتی log نمی‌شوند.

## Build

```bash
./gradlew :app:assembleDebug
```

اجرای تست‌های unit:

```bash
./gradlew :app:testDebugUnitTest
```

شناسهٔ برنامه: `com.nico2.app`
